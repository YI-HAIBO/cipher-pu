# E33 — 真实 RLWE 密文硬件端到端执行（Real-Ciphertext Execution）

**日期**：2026-10-24 ｜ **装置**：`e2e_ckks_mult_ctrl_m4` RTL（xsim 行为级，玩具配置 N=16, Q_IN=113, Q_OUT=97, Q_WIDTH=7）

## 1. 实验设计

与此前 E11（Python RLWE 模拟）和 M3-e（OpenFHE 数学对齐 7/7 PASS，仅数学层）不同，E33 把**真实生成的 RLWE 密钥/密文送进真实 RTL 数据通路**执行完整 CKKS 密文乘法链（4× `poly_mult` → m1 合并 → `keyswitch_pipe` → 2× `rescale`）：

- 真实三元秘密钥 s ∈ {−1,0,1}¹⁶（每例独立）；
- 真实重线性化 key（GHS 单对形式）：a ← U(Z₁₁₃¹⁶)，b = a·s + e_ks + s²，e_ks ← 离散高斯；
- 真实加密：small_c1 / noiseless 档 c₀ = m + e − c₁·s、c₁ ← 小范数（post-keyswitch 低范数域）；uniform 档 c₀ = a·s + e + m、c₁ = −a；
- 明文多项式 m₁, m₂ ∈ {−1,0,1}¹⁶，整数编码（Δ=1）；
- 环：Z₁₁₃[x]/(x¹⁶−1)（Z₁₁₃ 无 32 阶本原单位根，玩具环与 §3 声明一致）。

三档 regime 回答三个问题：

| regime | 用例 | 目标 |
|---|---|---|
| `uniform`（新鲜 RLWE） | 6 | Q1：bit-exact 通路验证 |
| `small_c1`（真噪声） | 4 | Q2/Q3：解密恢复 + 噪声预算 |
| `noiseless`（零噪声） | 2 | Q3：纯硬件伪影隔离 |

> **keyswitch 范畴说明（诚实声明）**：玩具 `keyswitch_pipe` 实现**单对**（非数位分解）重线性化 f₀ = d₀+d₂·b, f₁ = d₁−d₂·a，其引入误差为 d₂·e_ks。当 d₂ = c₁₁·c₁₂ 均匀（新鲜 RLWE 的必然结果）时该误差不可控，解密不成立——这不是硬件缺陷而是单对 keyswitch 的数学范畴。生产 CKKS 用数位分解keyswitch key 把误差压到 Σ Tⁱ·eᵢ。因此 uniform 档只验功能正确性，解密分析在 d₂ 天然小的 small_c1 档进行。

## 2. Q1 功能正确性：bit-exact 验证

- TB 侧逐系数 golden 比对：**12 PASS / 0 FAIL**（每例 32 系数 × 12 例）
- Python 侧从落盘 `e33_dut_f0/f1.hex` 复核：uniform 6/6, small_c1 4/4, noiseless 2/2

**结论 Q1**：真实 RLWE 密文经 RTL 全链执行，输出与 RTL-exact 参考模型（含 7-bit m1 合并回绕与 rescale 近似的精确语义）**逐系数 bit-exact**，384 系数零偏差——真实密文在 CIPHER-PU 数据通路上功能正确执行。

## 3. Q2 密码学正确性：真实 s 解密

解密流程：v = (f₀ + f₁·s) mod 97 → 尺度补偿解码 m̂ = round(v·113/97)（模切换使尺度收缩 q_out/q_in = 97/113）。
- `small_c1`（真噪声 σ=0.25）：解码恢复率 硬件 0.0%（0/64 系数）vs 理想模型 18.8%
- `noiseless`（零噪声）：解码恢复率 硬件 6.2% vs 理想模型 46.9%
- uniform 档解密不具密码学意义（见范畴说明）。

**结论 Q2**：在单对 keyswitch 精确域（d₂ 小范数）内，**理想模型**的解密恒等式 f₀+f₁·s = m₁m₂ + d₂·e_ks 成立（密码学构造正确）；但玩具模 ladder（113→97，比值 1.165 < 2，单级模降不足 1 bit）使整数编码（Δ=1）在解码分辨率极限处——即使理想模型，相邻明文整数在模切换后仅相距 0.86，叠加 ‖s‖₁·0.5 的模切换舍入噪声后不可靠解码。玩具硬件的恢复缺口**完全来自数据通路位宽伪影**（§4 定量分解，较理想模型再放大一个数量级），且这两类伪影在生产位宽下定量闭合（§5），不是架构性设计错误。

## 4. Q3 噪声预算与伪影分解

解密前置误差 e_v = v − m₁m₂·(97/113)（centered），分解为两个模型：

- **理想模型**：全 mod-113 精确算术 + 精确模切换 rescale——只含 RLWE 噪声增长（e₁m₂ + e₂m₁ + e₁e₂ + d₂·e_ks）与模切换舍入噪声（≤ ‖s‖₁·0.5）；
- **硬件（RTL-exact）模型**：额外含两处玩具位宽伪影：

  1. **m1 合并 7-bit 回绕**：m₁ₐ+m₁ᵦ ∈ [0,226) 以 7-bit 存储，sum ≥ 128 时回绕（模 128 而非模 113，每系数注入 −15）——玩具 Q_WIDTH=7 的直接后果；
  2. **玩具 rescale 近似**：correction = c·δ≫6 用 2⁷=128 近似 q=113，枚举可达域 [0,113) 得 max|Δ| = 12（均值 5.08；全定义域 [0,128) 边界点 |Δ| 最大 86，出现于 c ≡ q_in 处的模回绕不连续）。

noiseless 档实测：理想最大 |e_v| = 1.56637168141593（模切换舍入×‖s‖₁），硬件最大 |e_v| = 46.424778761061944、解码最大误差 59 vs 理想 2——两处伪影在玩具尺度下超出模切换噪声 1 个数量级。
small_c1 档实测：硬件最大 |e_v| = 47.28318584070797 vs 理想 4.283185840707965；m1 回绕 30/96 系数（回绕率 31%）。

**噪声预算**（budget = log₂(⌊q_out/2⌋ / max|e_v|)）：
- 理想模型：max|e_v| ≈ 4.283185840707965 → budget ≈ 3.5 bit（含真实 RLWE 噪声 + 模切换舍入）
- 硬件（玩具 RTL）：max|e_v| ≈ 47.28318584070797 → budget ≈ 0.0 bit——该数字反映**玩具位宽**而非密码学预算。另注：玩具模切换比 113/97 = 1.165 < 2，单次模切换不足 1 bit，整数尺度（Δ=1）本身处于解码分辨率极限；见 §5 生产外推。

## 5. 生产外推（位宽伪影在生产参数下消失）

- **m1 回绕概率**：生产 Q_WIDTH=45、q_in=17592186634241，P(m1ₐ+m1ᵦ ≥ 2⁴⁵) = **2.25e-15 /系数**（N=4096 每次乘法 9.21e-12）——可忽略；若需归零可将合并缓冲加宽 1 bit（RTL 勘误建议）。
- **rescale 近似**：correction 相对误差 = |2⁴⁴ − q_in|/q_in = **3.35e-08**（玩具 0.434）——生产 q_in ≈ 2⁴⁴ 使近似误差远低于 1 LSB。

## 6. 方法论与可复现性

- 向量种子 SEED=20261024（`random.Random` 确定性序列）；
- RTL-exact 参考模型语义与 2026-10-18 标定的 `_e2e_n16_gold.py` 一致（含 mod-128 合并、单次减法 keyswitch、rescale 位级公式），该模型已与 DUT 逐位核对；
- TB 输出经 negedge 握手采样后 `$writememh` 落盘，Python 复核避免$display 解析竞态；
- 限制声明：玩具环为正循环（x¹⁶−1）而非 CKKS 负循环（x¹⁶+1）；玩具尺度 Δ=1（玩具 rescale 不做尺度除法）；σ=0.25 为小尺度示意，生产σ=3.2 的预算见 E26/E31。

## 7. 论文整合要点

- §6/§8 新增 "real-ciphertext execution"：E33 证明真实 RLWE 工件（而非确定性测试向量）驱动下 CIPHER-PU 全链 bit-exact；
- 讨论：玩具位宽伪影（m1 回绕、rescale 近似）已量化并在生产参数下闭合（概率/相对误差数量级）；单对 keyswitch 范畴与数位分解列为生产 DARE/全 CKKS 的后续工作。
