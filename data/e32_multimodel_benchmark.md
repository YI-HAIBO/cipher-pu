# E32: 多模型端到端密文推理基准 (M7)
**日期**: 2026-10-24 14:04  
**参数**: N=2^12, log q=45, sigma_e=3.2, batch=512 slots, 功耗 0.824 W (E30 SAIF 实测), 468.84 effective poly_mults/s (E17/E21 实测)

## 方法
- 三个模型在相同训练预算下训练（3 epochs，MNIST 6k / CIFAR-10 8k 子集），
  明文精度 vs 密文精度（M4-h 噪声增长模型 r_hat = R_INIT x BASE_GROWTH^L + 自适应档位）
- 硬件成本模型：每个输出列一次密文-明文乘，poly_mults/batch = sum(d_out) + 层数
- 该成本模型在两个实测锚点上验证：MLP 140 vs 实测 141（+0.7%）、CNN 241 vs 实测 243（+0.8%）
- ResNet-18 为解析投影（非实测）

## ResNet-18 可行性
- 输出列总数 2,484,712 → 2,484,733 poly_mults/推理（batch=1，N=2^12 slots 无法摊销）
- 投影推理时间 1.47 小时 （468.84 poly_mults/s）
- 18 层乘法深度超过单素数 q=45-bit 噪声预算（E19: ~10-12 层安全），r_hat(18) = 1.59e-04
- 结论：ResNet-18 需多素数 RNS 模链 + bootstrap（Poseidon / ARK 量级），为本文 DARE bootstrap-lite 的未来工作方向

## 结论
1. **三模型密文推理均可运行**且密文精度与明文同量级（噪声模型保守估计下）
2. **成本模型在两个实测锚点验证误差 +0.7% / +0.8%**，可外推至新架构
3. **CIFAR-10 CNN** 首次给出端到端成本：76.2 推理/s（batch=512 摊销）
4. **ResNet-18 在 N=2^12 不可行**（噪声深度 + 时长），明确设计边界
